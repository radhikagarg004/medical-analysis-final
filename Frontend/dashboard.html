Project Overview

MedVision AI is an AI-powered chest X-ray analysis system using Deep Learning, Computer Vision and Explainable AI. Beyond classification, it evaluates image quality, estimates prediction uncertainty, explains model decisions, retrieves similar images and generates structured reports — making analysis transparent, interpretable and reliability-aware.
